# 📦 Product CRUD – Java MVC

## Description

This project is a CRUD application developed in Java following the **MVC (Model-View-Controller)** architecture pattern.

The system allows users to manage products through basic operations:

- Create a product
- Search products
- Update a product
- Delete a product

The main goal of this project is to apply clean architecture principles and proper separation of concerns.

---

## Architecture

This application follows the MVC pattern:

- **Model** → Represents the `Product` entity and handles data access logic.
- **View** → User interface (console or JSP/HTML depending on implementation).
- **Controller** → Manages user requests and coordinates between Model and View.
